# 🚀 Shivam Omer – Developer Portfolio

This repository contains the personal portfolio website for Shivam Omer, built with Next.js, TypeScript, and Tailwind CSS. It is designed to present a stronger professional story than a one-page resume by showcasing backend engineering, DevOps work, cloud automation, and a broad set of projects.

> 🌐 Live Site: [https://shivam-portfolio-gold-omega.vercel.app/](https://shivam-portfolio-gold-omega.vercel.app/)
> ✨ Responsive • Dark/Light Mode • Professional UI • Resume Ready

---

## 🔍 What the portfolio highlights

- 🧠 A polished About section aligned with the resume and professional profile
- 🧳 A detailed Experience section covering both backend and DevOps responsibilities
- 💻 A broader Projects page featuring backend systems, cloud/data engineering, and utility tools
- 📬 A Contact page with direct links to email, GitHub, LinkedIn, and phone
- 🌗 A clean light/dark theme with smooth transitions
- 🔍 SEO metadata, custom styling, and a resume download link

---

## 🛠️ Tech Stack

- Framework: Next.js + TypeScript
- Styling: Tailwind CSS
- Animations: Framer Motion
- Theme Management: next-themes
- Icons: lucide-react and react-icons
- Deployment: Vercel

## ▶️ Getting Started

```bash

npm install

# Start the development server
npm run dev

# Build for production
npm run build
```
